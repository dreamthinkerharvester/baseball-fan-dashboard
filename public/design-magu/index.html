🎨 필요한 에셋 (만들어주실 항목)

  • 팀 엠블럼 픽셀 PNG · 64×64 — 10팀 (KIA·LG·두산·삼성·롯데·한화·SSG·키움·NC·KT) · 도트풍 32-bit color
  • SD 선수 일러스트 · 96×96 PNG — KIA 주전 9명 (헬멧+유니폼 차림 흉상, 마구마구 SD 캐릭터 톤). 우선 김도영·박찬호·최정·최형우 4명만이라도 가능
  • 순위 메달 픽셀 · 32×32 — 1위 금메달, 2위 은메달, 3위 동메달 (이미 CSS gradient로 임시 구현 — 실제 일러스트로 교체 가능)
  • 섹션 아이콘 픽셀 · 24×24 — ⚾배트, 🏆트로피, 📅달력, 🚇지하철, 🔥불꽃, ★별 (이모지 대체용)
  • 홈/원정 뱃지 픽셀 · 36×16 — "홈" / "원정" 글자 박힌 미니 라벨 PNG (현재 CSS로 임시 구현)
  • (선택) 야구장 배경 패턴 타일 — 잔디 점선 / 모래 점선 / 펜스 텍스처 16×16 타일 (배경 장식용)
  • (선택) 효과 스프라이트 — 홈런/안타/삼진 텍스트 이펙트, 별 반짝이
