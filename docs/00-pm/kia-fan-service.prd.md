## Executive Summary

| 관점 | 내용 |
|------|------|
| **Problem** | KIA 팬은 경기 전후 "이 선수 진짜 잘하나, 운인가?"를 판단하고 싶지만, 스탯티즈는 PC 전용 복잡한 표이고 KBO앱은 세이버 지표가 없다. KIA 단일 팀 전용 뷰도 없다. 타율·ERA 같은 고전 지표로는 선수의 실제 기여를 읽기 어렵다는 불만이 팬 커뮤니티에 쌓여있다. |
| **Solution** | KIA 단일팀 전용, 세이버메트릭스 디폴트 표시(wRC+·WAR·wOBA·FIP·BABIP·K%-BB%·Barrel%·OPS+), 클래식 스탯 숨김·공개 토글, 마구마구 스타일 선수 카드 갤러리, 경기 일정·결과·순위 시각화를 하나의 모바일 친화 페이지에 제공한다. |
| **Pivot Delta (한 줄)** | 10구단 범용 대시보드 → KIA 단일팀 세이버 전문 서비스. 팀 선택 온보딩 제거, KIA 레드/블랙 브랜딩, 세이버 디폴트+클래식 숨김 토글이 핵심 변경. |
| **North Star Metric** | D30 기준 주 3회 이상 재방문율 >30% (경기 후 DAU 스파이크 지속 여부) |
| **Riskiest Assumption** | 캐주얼 KIA 팬이 클래식 스탯 숨김을 거부하지 않고 "탐험"으로 받아들인다. 실패 시 전체 차별화 포인트 소멸 → 토글 UX + 3일 Painted Door 실험으로 3주 내 검증 필수. |

## 1. Strategic Foundation

### 1-1. Beachhead Segment (Geoffrey Moore — Crossing the Chasm)

**선택된 비치헤드**: P1 김도현 유형 — KIA 팬 세이버 호기심 세그먼트 (27~35세 직장인)

#### 세그먼트 비교 평가

| 기준 (1~5점) | P1 세이버 호기심 팬 | P2 열정적 캐주얼 팬 | P3 파워유저/크리에이터 |
|-------------|:-----------------:|:-----------------:|:--------------------:|
| **Burning Pain** | **5** (스탯티즈 복잡·KIA 전용 뷰 없음·클래식 한계 인지) | 4 (빠른 결과 확인 욕구 강함) | 4 (콘텐츠 제작 소재 부족) |
| **Willingness to Engage** | **5** (세이버 학습 의욕 + 커뮤니티 논쟁 동기) | 3 (친숙한 언어 없으면 이탈 위험) | **5** (도구로서 즉시 활용) |
| **Winnable Market Share** | **5** (KIA 단일팀·세이버 조합 무경쟁 공백) | 3 (토글 UX 성패에 달림) | 4 (틈새 바이럴 채널 선점) |
| **Referral Potential** | 4 (커뮤니티 논쟁에서 링크 공유) | 3 (스크린샷 공유 가능하나 변동) | **5** (트위터·디시 데이터 콘텐츠 생산자) |
| **합계** | **19** | **13** | **18** |

**선택 근거**:
- P1은 세이버 지식 욕구와 KIA 팬 정체성이 교차하는 세그먼트다. 스탯티즈를 알지만 불편하고, KBO앱은 세이버가 없다. 이 간격을 메울 선택지가 없다.
- "느낌 vs 데이터 대비 UX"라는 감정적 훅이 P1의 동기(감각이 틀렸음을 확인하는 즐거움)와 정확히 일치한다.
- P3 파워유저는 점수(18)가 높지만, 콘텐츠 제작자로서 P1을 끌어들이는 배포 채널이므로 비치헤드는 P1, P3는 GTM 파트너로 활용한다.
- P2 캐주얼 팬은 토글 UX의 보호 대상. 비치헤드는 아니지만 이탈 방지 설계 필수. 세이버 용어 인라인 설명 + 토글이 P2를 붙잡는다.
- KIA 팬 커뮤니티(에펨코리아 호랑이 갤, 디시 인사이드, 트위터)에는 이미 데이터 논쟁 문화가 있어 P1 초기 확산이 자연스럽다.

#### 90일 고객 확보 계획

| 기간 | 활동 | 목표 |
|------|------|------|
| **1~2주 (Phase 0)** | 세이버 용어 이해도 Painted Door 실험 (wRC+ 셀 단독 노출, 3일) + 블러 토글 Figma hallway test (P1 5명) | 가설 검증. "클래식 숨김 거부율 <30%" 확인 |
| **3~4주** | MVP 배포 + 에펨 호랑이 갤 첫 게시. "세이버로만 보는 KIA" 캡처 1장 | DAU 300~500, 커뮤니티 댓글 반응 10건+ |
| **5~8주** | P3 파워유저에게 공유 카드 기능 조기 접근 제공. 트위터/X KIA 팬 계정 공유 | DAU 1,500. 공유 카드 주 50건+ |
| **9~12주** | Myth-Buster 패널 배포. 관전 포인트 카드 경기일 실시간 운영 | DAU 3,000. 주 3회+ 재방문율 >20% 달성 |

#### 핵심 메시지 (채널별)

- **에펨/디시**: "KIA 팬이라면 타율보다 wRC+ — 데이터가 말하는 진짜 기여도. 클래식 스탯 숨기고 세이버만 보는 KIA 전용 서비스 [링크]"
- **트위터/X**: "오늘 KIA vs XX. 상대 선발 FIP 4.8 vs KIA 타선 wRC+ 108. 오늘 KIA가 유리한 이유 → [공유 카드 이미지]"
- **데이터야구 유튜브**: "스탯티즈 표 보기 불편하셨나요? KIA 팬 전용 세이버 대시보드가 생겼습니다. wRC+ 한 줄 설명 포함."

```

  ├── 에펨 호랑이갤 + 디시 KIA갤 동시 스레드 ("타율 없애봤습니다")

[Post-Launch — 2~4주]
  ├── 피드백 수집: 토글 전환율 모니터링 (세이버→클래식 전환 비율)

  └── Myth-Buster 패널 데이터 준비 (체감 순위 vs wRC+ 순위 갭 산출)
```

## 4. Functional Requirements (MVP — Phase 1)

### F1. KIA 전용 즉시 진입 홈 (팀 선택 제거)

**목적**: O2-D 해결. TeamSelectionScreen/MyTeamSettings 완전 제거.

**기능 명세**:
- URL 접속 즉시 KIA 대시보드 표시. 팀 선택 화면 없음.
- KIA 레드/블랙 브랜딩: primary `#C8102E`, background `#1A1A1A`, text `#FFFFFF`
- 헤더: "KIA 타이거즈" 로고 + 오늘 날짜 + 시즌 순위 한 줄 (e.g. "현재 2위 · 41승 25패")
- localStorage `kia_saber_mode` = `true` (세이버 디폴트, 클래식 숨김 상태)

**엣지 케이스**:
- 비시즌: "2026 시즌 종료 — 최종 성적 보기" 배너 + 마지막 시즌 카드 표시
- localStorage 비활성화: 세이버 디폴트 상태로 고정 (토글 상태 세션 내 유지)

### F2. 세이버 온리 카드 + 클래식 숨김/공개 토글

**목적**: O1-A 해결. 핵심 차별화 기능.

**카드 세이버 필드 (디폴트)**:
- 타자 카드: wRC+ (메인), BABIP (보조), K%-BB% (보조)
- 투수 카드: FIP (메인), BABIP (보조), K%-BB% (보조)

**클래식 숨김 토글 UX**:
```
[세이버 디폴트 상태]
  - 클래식 스탯 셀: 블러 처리 (filter: blur(4px)) + 자물쇠 아이콘
  - 상단 토글 스위치: "클래식 스탯 보기" 레이블

[토글 ON 후 상태]
  - 블러 해제 → 타율·ERA 등 클래식 수치 공개
  - 토글 스위치 활성화 표시
  - 스낵바: "클래식 스탯이 표시됩니다. 세이버와 비교해보세요."
```

**세이버 용어 인라인 교육 오버레이**:
- 지표명(wRC+, FIP, BABIP, K%-BB%, OPS+, WAR, wOBA, Barrel%) 탭 시 툴팁 표시
- 포맷: "{지표명}: {한 줄 정의}. 이 선수 [{값}]은(는) 리그평균({기준}) 대비 {해석}."
- 예시: "wRC+: 리그평균=100. 이 선수 127 → 리그 평균보다 27% 더 득점에 기여."

**세이버 수집 현황 (기술 갭 명시)**:
- wRC+·FIP·BABIP·K%-BB%·OPS+: Statiz 크롤러 수집 완료 (기존 파이프라인 확장)
- **WAR·wOBA·Barrel%: 수집 파이프라인 미완성 — Phase 2 목표**. MVP에서는 미지원 상태 표시.
- 수집 불가 필드: "집계 중" 뱃지 표시 (빈 값 대신)

### F3. Myth-Buster 패널 (체감 vs 데이터 갭)

**목적**: O1-B 해결. KIA 팬의 "역전 케이스 발견" 즐거움 극대화.

**기능 명세**:
- KIA 선수 목록에서 클래식 지표 리그 순위 − wRC+ 리그 순위 = 갭 스코어 자동 산출
- 갭 스코어 절대값 기준 내림차순 정렬
- 표시 형식:
  ```
  [선수명]
  타율 리그 3위  ↔  wRC+ 리그 11위  (갭: -8)
  "타율은 높지만 출루·장타 효율이 낮습니다"
  ```
- 갭이 양수 (+): "체감보다 실제 기여가 높은 선수" — 초록 배지
- 갭이 음수 (-): "체감보다 실제 기여가 낮은 선수" — 주황 배지
- 공유 카드로 단독 내보내기 가능

**엣지 케이스**:
- 규정 타석/이닝 미달 선수: 패널에서 제외, 주석 처리
- 갭 스코어 0 선수: 패널 하단에 "일치" 묶음으로 표시

### F4. 관전 포인트 카드 (경기 당일)

**목적**: O2-E 해결. 경기 전 즉각적 가치 제공.

**기능 명세**:
- 경기 당일에만 표시. 상단 고정 카드.
- 내용: 상대 선발 투수 FIP + KIA 타선 wRC+ (최근 10경기 기준) 매치업
- 한 줄 해석: "KIA 타선 wRC+ [X], 상대 FIP [Y]. [유리/불리/팽팽] 매치업."
- FIP가 낮을수록 (투수 유리) + wRC+가 높을수록 (타선 유리) 매치업 판단
- 경기 결과 후: 관전 포인트 → "결과 요약 카드"로 자동 전환

**데이터 의존**:
- 상대 선발 투수 확정 여부: KBO 크롤러로 경기 당일 오전 10시부터 30분 주기 확인
- 확정 전: "상대 선발 미확정 — 오늘 경기 X팀" 플레이스홀더

### F5. KIA 경기 일정·결과·순위 시각화

**목적**: O2 해결. 단일팀 게임 감상 전용 뷰.

**구성 요소**:
1. **KIA 경기 캘린더 스트립**: 오늘 ± 3일 경기 일정. 홈/원정 구분. 결과 표시.
2. **KIA 순위 강조 배너**: 전체 10팀 순위 중 KIA 행 강조 + 게임차 시각화 (진행 바)
3. **최근 5경기 결과 타임라인**: 승/패/점수 + 홈런 친 선수 하이라이트 (wRC+ 기준 최고 기여자)
4. **KIA 경기 결과 "우리 시점" 요약 카드**: 경기 후 자동 생성. 최고 기여자 wRC+, 승리 투수 FIP.

**엣지 케이스**:
- 더블헤더: DH1/DH2 구분 레이블
- 우천 취소: "취소" 배지, 회색 처리
- 연장전: 이닝 수 표시

## 7. Technical Constraints & Decisions

### 기술 스택 (기존 유지)

| **호스팅** | Vercel 무료 티어 (기존) | 피벗 후도 동일. |

### 세이버 데이터 Gap 처리 전략

```
if (field === null && phase < 2) {
```

## 11. Phasing Roadmap

### Phase 0 — 검증 (1~2주, MVP 착수 전 필수)

**Exit Gate: 아래 3가지 미달 시 Phase 1 착수 금지**

| 검증 항목 | 실험 방법 | 성공 기준 |
|----------|----------|---------|
| Statiz 세이버 수집 안정성 | 크롤러 POC 7일 연속 실행 | wRC+·FIP 수집 성공률 95%+ |
| 클래식 숨김 수용률 | Painted Door: wRC+ 셀 단독 노출 3일 | "무슨 수치야?" 이탈율 <40% |
| 토글 UX 직관성 | Figma 프로토타입 hallway test (P1 5명, P2 3명) | "클래식 토글 쉽게 찾겠다" 70%+ |

**실패 시 피벗 플랜**:
- 크롤러 실패: KBO 공식 보조소스 역공학 → 핵심 세이버 계산식 직접 구현 검토
- 클래식 숨김 거부율 >40%: 디폴트를 세이버+클래식 병렬 표시로 변경 (포지셔닝 약화 감수)
- 토글 미발견 >50%: 토글을 카드 상단 상시 노출 버튼으로 교체

### Phase 1 — MVP (3~4주)

**범위**:
- [ ] F1: KIA 전용 즉시 진입 홈 (팀 선택 제거, KIA 브랜딩)

- [ ] F3: Myth-Buster 패널 (체감 vs 세이버 갭)
