**작성일**: 2026-05-09
**조사 범위**: KBO 야구팬 유저 페르소나 · 경쟁사 분석 · 시장 규모 · 고객 여정 · 감성 분석

## 1. 유저 페르소나 (3인)

### Persona A — 박지훈, 29세 (Primary-adjacent: 코어 매니아)

| 항목 | 내용 |
|------|------|
| **인구통계** | 남성, 29세, IT 개발자, 수도권 거주. 야구 역사 15년. |
| **Primary JTBD** | "경기 당일 선발 라인업부터 WAR·OPS·FIP까지 5분 안에 파악하고 싶다. 매일 아침 출근 전." |
| **현재 사용 도구** | 스탯티즈(statiz.co.kr), 네이버 스포츠, 야갤(DC), 엠엘비파크 KBO타운 |
| **빈도** | 하루 10회 이상 확인. 시즌 중 매일. |

**Pain Points**
1. 스탯티즈는 세이버 데이터가 완비되어 있지만 모바일 UI가 2010년대 수준. 폰에서 보기 너무 불편함 (심각도: 높음).
2. 네이버 스포츠는 UI는 깔끔하지만 WAR·wRC+ 같은 심층 지표가 없음. 두 사이트를 번갈아 봐야 함 (심각도: 중간).
3. 선수별 최근 10경기 트렌드를 한 눈에 볼 수 있는 도구가 없음. 숫자를 직접 엑셀에 정리하는 팬도 있음 (심각도: 중간).

**Desired Gains**
1. 세이버 지표 + 전통 스탯을 하나의 대시보드에서 동시에 볼 수 있으면 좋겠다.
2. 선수 카드 방식의 시각화로 성적 등급이 한눈에 들어오는 구조.
3. "이 선수 요즘 핫하다/콜드하다"를 수치 없이 카드 색상으로 직관적으로 파악.

**Unexpected Insight**: 통계 매니아임에도 불구하고, 숫자보다 시각적 등급화(카드 색상)에 더 강하게 반응한다. "숫자는 확인용, 색깔은 판단용"이라는 이분법적 인지 구조를 가짐.

**Product Fit**: 마구마구 카드 등급(Elite/Rare/Special/Normal)이 최근 성적 기반으로 동적 부여될 경우 강한 흡인력. 단, 스탯티즈 수준의 지표 깊이가 없으면 이 페르소나는 보조 도구로만 사용.

### Persona B — 이수연, 34세 (Primary: 직장인 캐주얼 팬)

| 항목 | 내용 |
|------|------|
| **인구통계** | 여성, 34세, 마케터, 서울 직장인. LG 트윈스 팬 7년. 시즌권 없음, 연 3~5회 직관. |
| **Primary JTBD** | "점심시간 5분 안에 우리 팀 오늘 경기 결과/일정/순위를 확인하고, 퇴근 후 경기를 볼지 결정하고 싶다." |
| **현재 사용 도구** | 네이버 스포츠 야구 탭, 가끔 카카오톡 오픈채팅 팬카페 |
| **빈도** | 점심·퇴근길(2회/일). 경기 없는 날은 거의 미접속. |

**Pain Points**
1. 네이버 스포츠에서 "마이팀" 알림 설정이 복잡함 (알림 ON → 스포츠 알림 → 구단 알림 → 마이팀 알림 — 총 4단계). 설정 안 한 팬이 대다수 (심각도: 높음).
2. 오늘 우리 팀 선발 투수가 누군지 찾으려면 3~4 탭을 넘어야 함. 일정 → 경기 → 예상 선발로 클릭이 많음 (심각도: 중간).
3. 모든 팀 정보가 혼재해서 "내 팀만 보기" 가 안 됨. 오늘 9개 팀 경기 목록에서 우리 팀 찾아야 함 (심각도: 중간).

**Desired Gains**
1. 앱 열면 첫 화면에서 내 팀 오늘 경기 결과/일정이 바로 보임.
2. 선수 카드 느낌으로 라인업이 보이면 경기 보고 싶은 기분이 생김.
3. 선수 이름 클릭 시 최근 성적이 쉬운 언어로 요약되어 나옴 (WAR 말고 "최근 10경기 타율 .340").

**Unexpected Insight**: 2030 여성 팬은 2024년 KBO 1000만 관중 달성의 핵심 동인이었지만(20대 여성 관심 증가율 77.9%), 이들이 정작 기존 야구 앱에서 받는 경험은 "남성 통계 중심 UI"에 맞춰져 있어 이탈률이 높다. 이 페르소나는 이미 팬이지만 앱 충성도는 거의 없다.

**Product Fit**: 이 제품의 핵심 타깃. "마이팀 설정 → 첫 화면 커스터마이즈" 온보딩을 30초 내로 끝내는 것이 핵심. 카드 UI가 SNS 공유 욕구를 자극할 경우 유기적 바이럴 가능.

### Persona C — 최민석, 41세 (추억충: 마구마구 세대)

| 항목 | 내용 |
|------|------|
| **인구통계** | 남성, 41세, 중간관리자, 경기도 거주. 2000년대 마구마구 헤비유저. 2015~2022년 야구 휴면. 2023년 류현진 복귀로 재입문. |
| **Primary JTBD** | "예전 마구마구에서 선수 카드 뒤집던 그 재미를 현실 KBO에서 다시 느끼고 싶다. 지금 선수 중 누가 레어 등급이야?" |
| **현재 사용 도구** | 포털(네이버) 검색 위주. 앱은 잘 안 씀. 유튜브 하이라이트 팬. |
| **빈도** | 주 3~4회. 주로 저녁 퇴근 후. |

**Pain Points**
1. 7~8년 공백 후 현재 선수단 파악이 어려움. "이 선수 잘 하는 선수야?" 판단 기준이 없음 (심각도: 높음).
2. 기존 앱은 숫자 나열 중심. 마구마구처럼 선수를 '캐릭터'로 느낄 수 있는 경험이 없음 (심각도: 중간).
3. 예전 레전드 선수(이승엽, 박찬호 시대)와 현역 비교가 불가. 맥락 없이 숫자만 나옴 (심각도: 낮음).

**Desired Gains**
1. 선수 카드가 마구마구처럼 등급별로 색이 다르게 표시되어, 누가 지금 핫한지 한눈에 보임.
2. 마이팀 라인업을 '내 덱' 느낌으로 볼 수 있음.
3. 카드 클릭 시 선수 소개가 게임 카드 뒷면 텍스트처럼 쉽고 재미있게 나옴.

**Unexpected Insight**: 이 페르소나는 통계 해석 능력보다 '게임화된 경험'을 더 원한다. 스탯 수치 자체보다 "이 선수 Elite야, 레어야?"라는 등급 판단을 더 빠르게 소비한다. 재입문 팬일수록 진입 장벽을 낮추는 게임화 UI가 핵심 전환 요소.

**Product Fit**: 마구마구 IP 노스탤지어가 강력한 초기 유입 훅(hook). 단, 7년 이상 공백이 있어 선수 정보 학습 곡선이 있음. 카드 등급 + 간단한 성적 요약이 재미와 정보를 동시에 제공해야 함.

## 2. 경쟁사 분석 (5개)

### 경쟁사 개요 테이블

| 경쟁사 | 강점 | 약점 | 우리의 기회 |
|--------|------|------|-------------|
| 네이버 스포츠 야구 | 압도적 트래픽, 마이팀 알림, 오픈톡 커뮤니티 | 세이버 지표 없음, 설정 복잡, 중계권 없음, UI 정보 과부하 | 마이팀 1화면 집중 + 심층 지표 |

| 프로야구 LIVE / ruta | 실시간 스코어·피치 데이터, 앱 완성도 | 커뮤니티 없음, 카드 개념 없음 | 게임화 레이어 + 마이팀 집중 뷰 |

### 2-1. 네이버 스포츠 야구

**프로필**: 네이버가 운영하는 국내 최대 스포츠 포털. 2024년 기준 10개 구단 MY팀 추가 누적 이용자 약 336만 명. 야구 오픈톡 개막 주 방문자 246% 급증.

**핵심 강점**:
- 국내 검색 포털 1위 인프라 기반 자연 유입
- 마이팀 알림, 오픈톡 커뮤니티, 기사·하이라이트 통합
- 2025년 기준 문자중계·승부예측·응원 기능

**약점 및 격차**:
- 2024년부터 KBO 생중계 중단 (티빙으로 이관). 핵심 콘텐츠 부재.
- WAR·wRC+·FIP 등 세이버 지표 완전 부재
- UI 개편 후 전체 경기 목록이 스크롤 없이 한눈에 안 보임 — 루리웹 등 커뮤니티에서 불만 제기
- 문자중계 채팅의 스팸·비방 댓글 관리 부실

**위협 수준**: 높음 (압도적 MAU). 단 "마이팀 집중 + 세이버" 니치에서는 공백 존재.

---

### 2-2. KBO 공식앱 & 다음 스포츠

**프로필**: KBO 공식앱(sports2i 운영)은 공식 데이터 독점 접근. 다음 스포츠는 카카오 운영, 2025년 필드뷰·AI 결과 요약 기능 개편. 다음 스포츠 2025년 야구 페이지 조회수 전년 대비 +26%, 방문자 +11%.

**핵심 강점**:
- KBO 공식앱: 공식 라이선스 데이터, 올스타 투표, 굿즈 구매
- 다음 스포츠: 필드뷰 그래픽 중계, AI 경기 요약, 구단별 카페 연동, MVP 투표

**약점 및 격차**:
- KBO 공식앱: 구글 플레이 리뷰에서 "버튼 작동 안 함", "날씨 정보 2020년 3월에 고정", "PC에서만 회원가입 가능" 등 기초 완성도 문제 다수
- 다음 스포츠: 범용 포털이라 야구 전용 경험 불가. 카드 개념·게임화 UX 없음
- 두 서비스 모두 선수를 '캐릭터'로 경험하는 요소 전무

**위협 수준**: 중간. 다음의 성장세 주목 필요.

---

### 2-3. 스탯티즈 (STATIZ, statiz.co.kr)

**프로필**: 2007년 개설, 2015년 재오픈. KBO 세이버메트릭스 사실상 표준. 야구 해설자·기자·분석가가 기본 참고자료로 사용. STATIZ PLUS(스포키) 프리미엄 버전 존재.

**핵심 강점**:
- WAR, wRC+, FIP, 투구 궤적, 타구 분포 등 국내 최고 수준 지표
- 선수 간 비교, 상황별(주자·볼카운트) 성적, 역대 시즌 비교
- 야구 커뮤니티 내 신뢰도 1위

**약점 및 격차**:
- 모바일 반응형 UI 사실상 없음. 데스크탑 중심 테이블 레이아웃.
- 시각화·색상 구분 없음. 숫자 나열 일변도.
- 비등록 사용자에게 일부 기능 제한. 커뮤니티 기능 없음.
- "스탯에 맥락 부여" 기능 부재 — "이 수치가 좋은 건지 나쁜 건지" 판단 도움 없음

**위협 수준**: 데이터 신뢰도 측면에서 높음. UX 측면에서는 우리의 기회.

---

### 2-4. MyKBO Stats (mykbostats.com)

**프로필**: 2003년 창설된 영어권 KBO 팬 커뮤니티 MyKBO.net의 통계 파생 서비스. 팬이 만든 비공식 사이트. iOS/Android 앱 보유.

**핵심 강점**:
- KBO 전체를 영어로 완전 번역 (기계+인간 번역 혼합)
- 실시간 알림(라인업 변경, 점수 변동, 홈런)
- 경기장 날씨, 스케줄, 영상 링크 통합
- 팬 친화적 UI, "made by fans for fans" 정체성

**약점 및 격차**:
- 한국어 미지원 → 국내 팬 대상 아님
- 세이버 지표보다 기본 스탯 중심
- 카드 UI·게임화 없음
- 마이팀 선수 라인업 집중 뷰 없음

**위협 수준**: 낮음 (타깃 고객 비중첩). 단 UI/UX 아이디어 참고 가치 있음.

---

### 2-5. 프로야구 LIVE / ruta (KBO STATS 리브랜딩)

**프로필**: 프로야구 LIVE는 국내 야구 전문 앱. ruta(구 KBO STATS)는 최근 전면 개편, 실시간 스코어·이닝별 흐름·구종 위치 데이터 제공. 2024년 기준 KBO STATS 순 이용자 약 26만 명.

**핵심 강점**:
- ruta: 실시간 피치 데이터, 구종 위치, 이닝 흐름 — 경기 중 사용성 특화
- 프로야구 LIVE: 커뮤니티 기능(응원 게시판), 전력 분석, 우승투수 예측 이벤트
- 앱 로딩 속도 최적화, 다양한 화면 비율 지원

**약점 및 격차**:
- 게임화 레이어 없음. 선수를 카드 형태로 경험하는 요소 전무.
- 마이팀 커스터마이즈 뷰가 제한적
- 스탯티즈 수준의 세이버 깊이 없음

**위협 수준**: 중간. 모바일 앱 경험에서 직접 경쟁.

---

### 차별화 전략 종합

**우리 제품이 채울 수 있는 2가지 핵심 격차**:

1. **"세이버 데이터 × 카드 UI" 공백**: 스탯티즈는 데이터는 있지만 모바일 UX가 없음. 네이버는 UX는 있지만 심층 지표가 없음. 이 두 축을 결합한 서비스가 현재 국내에 없다.

2. **"마이팀 전용 1화면" 공백**: 모든 경쟁사는 리그 전체 정보를 기본으로 보여주고, 마이팀은 필터링 옵션으로 제공한다. 반대로 설계 — 마이팀이 기본, 리그가 선택 — 하는 제품이 없다.

**권장 포지셔닝**: "KBO 팬을 위한 마이팀 첫 화면 + 마구마구 카드 UX + 모바일 최적화 세이버 대시보드"

---

## 3. 시장 규모 (TAM/SAM/SOM)

### 방법론 개요

- **Top-Down**: KBO 리그 팬 규모 × 디지털 미디어 침투율 × ARPU 추정
- **Bottom-Up**: 야구 전문 앱 사용자 수 × 광고·프리미엄 수익 단가

---

### Top-Down 추정

| 단계 | 수치 | 근거 |
|------|------|------|
| 한국 스포츠 관심 인구 | ~2,400만 명 | 갤럽 조사: 야구 관심층 성인 남성 42%, 여성 27%로 추산 |
| KBO 적극 팬 (연 1회 이상 소비) | ~1,000만 명 | 2024년 관중 1,088만, 2025년 1,231만 — TV·모바일 시청 포함 추정 |
| 모바일 앱 실제 이용자 | ~200만 명 | KBO 공식앱 22만 + KBO STATS 26만 + 기타 앱, 중복 제거 추정치 |
| 야구 전용 디지털 서비스 유료 전환 가능층 | ~50만 명 | 티빙 KBO 중계 유료 가입자 행동 기반 추정 |

**TAM**: KBO 야구팬 디지털 서비스 광고 + 프리미엄 시장
- 야구 관련 디지털 광고 소비 가능 인구 약 200만 명 × ARPU 추정 연 3,000원(광고 기반) = **약 60억 원/년**
- 프리미엄 구독 전환 가능 인구 약 20만 명 × 월 1,000원 × 12개월 = **약 24억 원/년**
- TAM 합산 = **약 80~100억 원/년**

---

### Bottom-Up 추정

| 항목 | 수치 |
|------|------|
| 야구 정보 앱 총 활성 사용자 (추정) | 약 150~200만 MAU |
| 광고 기반 ARPU (국내 스포츠 앱 평균) | 월 약 200~300원 |
| 연간 광고 수익 (150만 × 250원 × 12) | 약 45억 원 |
| 프리미엄 구독 전환율 가정 (3%) | 약 4.5만 명 |
| 프리미엄 ARPU (월 1,500원) | 연 약 8억 원 |
| **Bottom-Up TAM 합계** | **약 50~60억 원/년** |

---

### TAM / SAM / SOM

| 지표 | 현재 (2026) | 3년 후 (2028) | 산정 방법 |
|------|------------|-------------|---------|
| **TAM** | 80억 원/년 | 110억 원/년 | KBO 팬 디지털 서비스 전체 시장 (광고+구독). KBO 관중 연 +10% 성장 가정. |
| **SAM** | 20억 원/년 | 30억 원/년 | 마이팀 전용 + 세이버 집중 니치 유저층 (전체 MAU의 20~25%) |
| **SOM** | 1.5억 원/년 | 6억 원/년 | 1년차 MAU 10만, 3년차 MAU 40만 목표. 광고+선택적 프리미엄. |

**주요 가정**:
1. KBO 관중 증가세가 2025년 1,231만 명에서 연 5~10% 추가 성장 유지 (자신도: 중간)
2. 야구 전용 앱 MAU는 현재 약 150~200만으로 추정 (신뢰도: 중간 — 공개 데이터 부족)
3. 모바일 광고 CPM 기준 국내 스포츠 앱 약 2,000~3,000원 수준 적용 (신뢰도: 중간)
4. 마구마구 세대(30~40대 남성) 추억 마케팅으로 신규 유입 시 전환율 상향 가능 (자신도: 낮음 — 가설)

**성장 드라이버**:
- KBO 2024~2025년 연속 흥행 (1000만→1231만) — 팬 기반 확대 중
- 2030 여성 팬 급증 — 새로운 세그먼트 공략 기회
- 마구마구(넷마블) 모바일 게임 지속 서비스 — 카드 UI 친숙도 기반 유지

## 4. 고객 여정 지도 (Customer Journey Map)

**Primary Persona**: Persona B — 이수연 (34세 직장인 LG 팬)
**시나리오**: 평일 경기일 (주중 저녁 6:30 경기)

| 단계 | 터치포인트 | 행동 | 생각 | 감정 | Pain Points | 기회 |
|------|-----------|------|------|------|-------------|------|
| **인지 (오전 8시)** | 네이버 앱 알림 또는 카카오톡 팬카페 | 출근 준비 중 폰 확인. "오늘 경기 있나?" 확인 | "오늘 LG 경기네. 몇 시야?" | 기대·호기심 | 알림 설정이 복잡해 알림 자체를 꺼놓은 경우 많음 | 마이팀 설정만 하면 경기 당일 오전 자동 알림 발송 |
| **탐색 (점심 12시)** | 네이버 스포츠 야구 탭 | 스코어보드 → 우리 팀 찾기 → 오늘 선발 투수 검색 | "오늘 선발이 누구지? 잘 하는 투수야?" | 궁금함·약간 불편 | 9개 팀 경기 목록에서 마이팀 찾기, 선발 투수 실력 판단 불가 | 마이팀 첫 화면 — 오늘 선발 카드를 등급 색상으로 즉시 표시 |
| **결정 (퇴근 전 5시)** | 포털 스포츠, 팬카페 | "오늘 경기 볼까?" 결정. 티빙 켤지 판단. | "선발이 에이스면 보자. 컨디션 어때?" | 설레거나 무관심 | 선발 최근 성적을 빠르게 판단할 수 없음. 클릭 여러 번 필요. | 카드 클릭 1회 → "최근 5선발 평균 자책점 2.80 / 우수" 요약 |
| **온보딩 (첫 방문)** | baseball-fan-dashboard 진입 | 마이팀 선택, 카드 UI 구경 | "마구마구 느낌이네? 신기하다" | 흥미·가벼운 놀라움 | 마이팀 설정 과정이 3단계 이상이면 이탈 | 원클릭 마이팀 선택 → 즉시 대시보드 진입 (회원가입 없이) |
| **실사용 (경기 중 저녁 7시)** | 모바일 대시보드, 경기 중간 확인 | 이닝 사이 스코어·타선 순서 확인. 다음 타자 카드 클릭. | "다음 타자 오늘 어때? 카드 색 빨간색이네 — 핫하구나" | 몰입·즐거움 | 실시간 갱신 속도가 느리거나 크롤링 지연 시 신뢰 하락 | 경기 중 카드 색상이 실시간 성적 반영 (최근 10경기 기준 동적 등급) |
| **사후 (다음날 출근길)** | 대시보드 어제 경기 요약 | 어젯밤 결과 확인, 팀 순위 변동 체크 | "우리 몇 위야? 게임차 얼마야?" | 만족 또는 아쉬움 | 결과 요약을 보기 위해 다시 앱 열기가 귀찮음 | "어제 경기 요약" 섹션 — 1줄 결과 + 순위 변동 카드 |
| **추천 (자연 공유)** | SNS (인스타·카카오톡) | 선수 카드 캡처 → 친구에게 공유 | "오늘 이 선수 Elite네ㅋㅋ 공유해야지" | 유쾌함·자랑 욕구 | 기존 앱은 공유할 만한 시각적 요소 없음 | 선수 카드 1탭 → 공유 이미지 자동 생성 기능 |

**Moments of Truth (핵심 전환 순간)**:
1. **온보딩 30초**: 마이팀 선택 후 카드 라인업이 즉시 뜨는 순간 — 이때 "오 이거다" 반응 없으면 이탈
2. **카드 등급 첫 인식**: "Elite는 보라색, 레어는 빨간색" — 설명 없이 직관적으로 이해되는지 여부
3. **경기 후 요약 재방문**: 다음 날 오전 재방문이 형성되면 습관 루프 완성

**최대 Pain Point**: 탐색 단계 — 마이팀 정보를 찾기까지 클릭 3~4회 필요

**최대 기회**: 실사용 단계 — 경기 중 카드 색상으로 선수 컨디션을 비언어적으로 전달
