## 1. Value Proposition (JTBD 6-Part)

| 파트 | 내용 |
|------|------|
| **Who** | KBO를 매일 챙기는 한국 야구팬 (20~40대). 특정 팀을 응원하고, 선수 성적과 라인업에 관심이 많으며, 마구마구 카드게임에 친숙한 세대 |
| **Why (문제/JTBD)** | 경기 일정, 팀 라인업, 선수 기록을 한 화면에서 빠르게 확인하고 싶다. 네이버·KBO앱은 정보가 흩어져 있고 UX가 무겁다. "경기 전 5분 안에 오늘 우리팀 상황을 파악하고 싶다." |
| **What Before (현재 상황)** | 네이버 스포츠 → 다음 스포츠 → KBO 공식앱을 탭마다 열어가며 확인. 선수 카드 느낌의 시각화는 없음. 정보가 텍스트 테이블 위주라 한눈에 안 들어옴 |
| **How (솔루션)** | 단일 페이지 대시보드: (1) 오늘/이번주 팀 일정 한눈에, (2) 마이팀 선택 시 라인업을 마구마구 카드 스타일로 표시, (3) 카드 색상이 최근 성적 등급(엘리트=보라/레어=빨강/스페셜=노랑/노멀=파랑)을 즉각 전달, (4) 카드 클릭으로 시즌·역대 기록 드릴다운 |
| **What After (개선 후)** | 경기 전 30초면 라인업 상태 파악 완료. "오늘 3루수 컨디션이 레어급이네" 같은 직관적 판단 가능. 친구들과 카드 등급으로 선수 비교하는 대화 생김 |
| **Alternatives (대안)** | 네이버 스포츠 (정보 많지만 무겁고 광고 많음), KBO 공식앱 (공식 데이터지만 UX 구림), 다음 스포츠 (유사), 야구 커뮤니티 직접 눈팅 (느림). 이 앱의 차별점: 마구마구 카드 UX + info-dense 단일 페이지 |

**Value Prop Statement**: KBO 팬이 경기 전 30초 안에 마이팀 라인업의 컨디션을 마구마구 카드 색상으로 즉각 파악하고, 선수 기록을 한 화면에서 드릴다운할 수 있는 정보 밀도 높은 단일 페이지 대시보드.

## 2. Lean Canvas

| 섹션 | 내용 |
|------|------|
| **Problem** | 1. KBO 정보가 네이버/다음/KBO앱에 분산 — 경기 전 확인에 3~5개 탭 필요 2. 선수 컨디션/성적을 텍스트 테이블로만 제공 — 직관적 판단 불가 3. 마구마구 카드 감성을 살린 야구 정보 뷰어가 시장에 없음 |
| **Solution** | 1. 팀별 일정 + 마이팀 선택으로 간소화된 뷰 2. 라인업을 마구마구 카드 스타일(색상=성적 등급)로 시각화 3. 카드 클릭 → 선수 시즌·역대 기록 드릴다운 |
| **UVP** | "마구마구 카드로 보는 KBO 라인업 — 오늘 우리팀 컨디션 30초 판독" |
| **Unfair Advantage** | 마구마구 UX 언어에 대한 팬 감성적 연결 (네이버는 이 감성을 절대 따라하지 않음). 개인 프로젝트의 빠른 반복 속도. 마구마구 세대(30~40대) 팬덤의 향수 |
| **Customer Segments** | 주요: 20~40대 KBO 적극 관람 팬, 특히 마구마구 게임 경험자. 얼리어답터: 야구 커뮤니티(야갤, 엠팍, 팀별 카페) 활성 유저 |
| **Channels** | 야구 온라인 커뮤니티 직접 공유 (야갤/팀별 카페), 트위터/X 야구팬 계정, 지인 바이럴. URL 공유만으로 접근 (앱스토어 불필요) |
| **Revenue Streams** | MVP: 무료. 이후: 자발적 후원(Buy Me a Coffee/토스), 장기 트래픽 확보 후 비침습적 배너 광고 검토. 유료화 계획 없음 (패션 프로젝트) |
| **Cost Structure** | 호스팅: Vercel/Netlify 무료 티어. 도메인: 연 ~1~2만원. 개발 시간(기회비용). 데이터 크롤링 서버: 무료 티어 or GitHub Actions 스케줄러. 실질 현금 비용 거의 0 |
| **Key Metrics** | DAU (경기일 vs 비경기일 비율), 세션당 카드 클릭 수, 마이팀 선택 전환율, 커뮤니티 공유 언급 수 (바이럴 지표) |

## 3. SWOT Analysis

| | Helpful | Harmful |
|---|---------|---------|
| **Internal** | **Strengths**: 1. 마구마구 카드 UX라는 명확한 차별화 시각 언어 2. 단일 페이지 info-dense 설계 → 경쟁앱 대비 속도·단순성 우위 3. 개인 프로젝트 → 의사결정 빠름, 피벗 자유로움 4. 웹 기반 → 앱스토어 승인 불필요, URL 공유 즉시 확산 | **Weaknesses**: 1. 데이터 소스가 크롤링 의존 → 사이트 구조 변경 시 파이프라인 깨짐 2. 유지보수 인력 = 개인 1명 → 시즌 중 장애 대응 리소스 부족 3. 마구마구 IP를 직접 사용하면 법적 분쟁 가능성 4. 공식 KBO API 없음 → 데이터 정확도·실시간성 한계 |
| **External** | **Opportunities**: 1. KBO 관람 인구 꾸준히 증가 (2023~2025 역대급 관중) 2. 야구 커뮤니티의 자체 도구 공유 문화 → 바이럴 용이 3. 마구마구 게임 종료(2023) 후 해당 UX 향수 수요 존재 4. 웹 크롤링 기반 팬 프로젝트의 법적 관례상 용인 분위기 | **Threats**: 1. **[#1 핵심 리스크]** 네오위즈 마구마구 IP 침해 클레임 — 카드 디자인·색상 시스템 직접 복제 시 C&D 가능 2. KBO/구단 공식 사이트 크롤링 차단 (robots.txt 강화, IP 블락) 3. 네이버가 유사 카드 UX 도입 시 차별화 소멸 4. 개인 프로젝트 번아웃 → 시즌 중반 방치 위험 |

**SO 전략**: 마구마구 감성 + 빠른 반복으로 야구 커뮤니티 얼리어답터를 먼저 확보. KBO 관중 증가 트렌드에 올라타 시즌 초(3~4월)에 런칭 집중.

**WT 전략**: 마구마구 UI를 "영감 받은 오마주"로 포지셔닝하되 로고·상표·브랜드명은 사용 금지. 크롤링 대상을 공개 통계 사이트(statiz, 스탯티즈)로 제한해 KBO 직접 차단 리스크 분산.

## 4. Porter's Five Forces (Lite — KBO 정보앱 시장)

| Force | 강도 | 핵심 요인 | 시사점 |
|-------|:----:|-----------|--------|
| **경쟁 강도** | 높음 | 네이버 스포츠, 다음 스포츠, KBO 공식앱이 트래픽 대부분 장악. 그러나 카드 UX 차별화 니치에서는 경쟁자 없음 | 전면 경쟁 금물. 카드 UX + 마이팀 집중이라는 좁은 포지션 유지 |
| **공급자 파워** | 중간 | 데이터 공급자 = 크롤링 대상 사이트(statiz, KBO). 공식 API 없으므로 공급자가 단방에 차단 가능 | 다수 데이터 소스 분산 크롤링, 캐싱 레이어로 단일 의존 해소 |
| **구매자 파워** | 낮음 | 무료 서비스 → 이탈 비용 0. 그러나 전환도 비용 0이라 충성도 확보가 진짜 과제 | 카드 UX 감성 + 빠른 로딩으로 습관 형성이 핵심 |
| **대체재 위협** | 높음 | 네이버 스포츠는 사실상 완전 대체재. 단, "마구마구 카드 느낌"은 대체 불가 | UX 감성이 유일한 해자. 감성이 희석되면 존재 의미 소멸 |
| **신규 진입 위협** | 낮음 | 진입 장벽 낮으나 (웹앱+크롤링), 마구마구 감성 재현은 단순 기술 복제로 불가. 대형 플랫폼은 IP 리스크로 접근 기피 | 감성 UX 리더십 유지가 방어선 |

**종합 산업 매력도**: 중간 (니치 포지션 안에서는 매력적, 전체 KBO 정보 시장에서는 비매력적)

## 5. Pricing Strategy

**추천 모델: 무료 → 자발적 후원**

| 단계 | 모델 | 근거 |
|------|------|------|
| MVP ~ 1년 | 완전 무료 | 트래픽·신뢰 확보 우선. 유료화는 커뮤니티 반감 유발 |
| 1년 후 (선택) | Buy Me a Coffee / 토스 후원 링크 | 한국 야구팬 커뮤니티는 좋은 팬 프로젝트에 자발적 소액 후원 문화 있음 |
| 장기 (선택) | 비침습 배너 (Google AdSense) | DAU 1,000+ 달성 후 검토. 배너가 카드 UX를 해치지 않는 위치에 한정 |

**Van Westendorp (참고용)**:
- Too cheap (의심 가격): 0원 → 무료가 맞음
- Acceptable: 후원 500~2,000원/회
- Too expensive: 월정액 구독 → 팬 프로젝트에 맞지 않음

**결론**: 수익화는 목표가 아님. 후원 버튼은 "커피 한 잔" 프레이밍으로 심리 부담 최소화.

## 6. Ansoff Matrix

```
                    기존 제품          새로운 제품
기존 시장     [ 시장 침투 ]        [제품 개발] ← 여기
새로운 시장   [시장 개발]          [다각화]
```

**위치: 제품 개발 (Product Development)**

- **시장**: 기존 KBO 팬 (이미 존재, 이미 네이버/다음 쓰는 사람들)
- **제품**: 새로운 UX (마구마구 카드 대시보드) — 시장에 없던 방식

**시사점**:
- 새로운 시장을 만들 필요 없음 → KBO 팬 커뮤니티에만 집중
- 리스크는 "이 새로운 UX가 기존 팬이 원하는 것인가" → MVP로 빠르게 검증
- 마켓 개발(새로운 시장: 예: 일본 NPB 팬)은 MVP 검증 후 고려

## 7. Strategic Synthesis

| 차원 | 핵심 인사이트 | 제품 시사점 |
|------|-------------|------------|
| 포지셔닝 | 마구마구 카드 UX가 유일한 해자. 이 감성이 희석되면 차별화 소멸 | 카드 색상 등급 시스템을 타협 없이 구현. 텍스트 테이블로 후퇴 금지 |
| 데이터 리스크 | 단일 크롤링 소스 의존은 즉시 장애로 이어짐 | statiz + KBO + 구단 공식 사이트 최소 2개 소스 크롤링, 캐시 TTL 관리 |
| IP 리스크 | 마구마구 상표·로고 무단 사용 시 C&D 가능 | 카드 "스타일"만 영감으로. 브랜드명·로고 사용 금지. 앱 이름은 독자적으로 |
| 런칭 타이밍 | KBO 시즌(3~10월)에 DAU 집중. 비시즌 개발 기간으로 활용 | 3월 개막 전 MVP 배포 목표로 로드맵 역산 |
| 성장 경로 | 커뮤니티 바이럴이 유일한 채널 | 기능보다 "공유하고 싶은 카드 화면" UX 우선. 스크린샷 공유 유도 |

## 8. Key Assumptions to Validate

| # | 가정 | 리스크 | 검증 방법 |
|---|------|--------|----------|
| 1 | 팬들이 마구마구 카드 UX를 "멋있다"고 인식한다 | 높음 | MVP 스크린샷을 야갤/팀 카페에 올려 반응 확인 (클릭 없이 이미지 공유만으로도 검증 가능) |
| 2 | statiz/스탯티즈 크롤링이 안정적으로 작동한다 | 높음 | 로봇 정책 확인, 헤더 위장, 속도 제한 준수로 차단 회피 가능성 사전 테스트 |
| 3 | 마이팀 기능이 리텐션을 만든다 (경기마다 재방문) | 중간 | DAU vs 경기일 상관관계 초기 2주 데이터로 확인 |
| 4 | 네오위즈가 팬 오마주 프로젝트에 C&D를 보내지 않는다 | 중간 | 마구마구 브랜드 미사용, 상업적 수익 없음 → 리스크 최소화. 단, 모니터링 필요 |
| 5 | 개인이 시즌 내내 크롤러를 유지할 수 있다 | 중간 | GitHub Actions 스케줄러 자동화, 장애 알림(Discord 웹훅) 세팅 |
