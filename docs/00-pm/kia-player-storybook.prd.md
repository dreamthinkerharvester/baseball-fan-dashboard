# PRD: KIA Player Storybook (기아 선수 서사 + 블로그 초안 빌더)

**버전**: 1.0
**작성일**: 2026-05-11
**작성자**: 사용자 본인 + PM 합성
**상태**: 초안 (Draft)
**연관 Feature**: baseball-fan-dashboard (v1 완료 · 인프라·데이터 모델 재사용)

---

## Executive Summary

| 관점 | 내용 |
|------|------|
| **Problem** | 야구 블로그 글을 쓸 때 선수 1명 분 자료를 모으는 데 30~60분이 든다. 당일 기록(KBO 박스스코어) · 통산 기록(스탯티즈) · 전성기 시즌 식별 · 그 시기 뉴스 클립 · 인터뷰 인용 · 부상·이적 타임라인을 5~6개 사이트를 오가며 수집·정리해야 한다. |
| **Solution** | 기아 선수명 1개 입력 → 4개 데이터 영역(당일 기록 · 전성기 기록 · 과거 뉴스 클립 · 선수 서사)을 자동 수집·합성한 한 페이지 패널 + 그대로 복사 가능한 1500자+ 블로그 초안 마크다운을 생성. |
| **Core Value** | "선수 1명 글 1편 = 5분" — 자료 수집 시간을 30분→5분으로 압축. 출력은 그대로 발행하지 않고 사용자가 다듬는 초안(draft). |
| **Scope (Phase 1)** | **기아 타이거즈만**. 10구단 확장은 Phase 2. |

## 2. 핵심 사용자 흐름 (User Flow)

```
[1] /storybook 페이지 진입
       ↓
[2] 기아 선수 검색창 또는 KIA 선수 카드 그리드에서 선수 1명 클릭
       ↓
[3] 로딩(2~5초) — 백엔드가 4개 데이터 소스 병렬 fetch
       ↓
[4] 결과 패널 4섹션 (당일 / 전성기 / 뉴스 / 서사) + 블로그 초안 미리보기
       ↓
[5] "복사" 버튼 → 클립보드에 마크다운 / "다운로드" 버튼 → .md 파일
       ↓
[6] 사용자가 본인 블로그(티스토리·네이버 등)에 붙여넣고 다듬어서 발행
```

## 3. 기능 요구사항 (F)

### F1. 당일 기록 (Today's Performance)

- **타자**: 타석 · 안타 · 홈런 · 타점 · 볼넷 · 삼진 · 시즌 누적 변동
- **투수**: 이닝 · 자책 · 탈삼진 · 볼넷 · 시즌 누적 변동
- **출처**: KBO 공식 박스스코어 (기존 `scripts/crawler/` 재사용)
- **출전 안 했으면**: "오늘 경기 결장" + 최근 5경기 기록으로 fallback

### F2. 전성기 시즌 자동 감지 (Prime Season Detection)

- 통산 시즌 기록을 스탯티즈/KBO에서 수집 → WAR / OPS / 방어율 등 핵심 지표 기반 자동 best year 추출
- **타자**: WAR 최고 시즌 1개 + 보조로 OPS 최고 시즌
- **투수**: WAR 최고 시즌 1개 + 보조로 ERA 최저 시즌
- 신인급(3년 미만)이면 "전성기 아직" 라벨 + 현재 시즌 강조

### F3. 과거 뉴스 클립 (Vintage News)

- 전성기 시즌 ±1년 범위에서 네이버 뉴스 검색 API로 헤드라인 + URL + 발행일 5~10건
- **제외 키워드**: "사건사고", "음주", "스캔들" 등 (선수 명예훼손 방지)
- **출처 명시 필수**: 헤드라인 옆에 "(출처: ○○일보, YYYY-MM-DD)" 링크

### F4. 선수 서사 (Player Narrative)

- 입단·드래프트 → 1군 데뷔 → 주목할 시즌(전성기) → 부상·슬럼프 → 회복·이적 → 현재
- 출처: 나무위키 + KBO 공식 선수 페이지 + 인터뷰 인용 (출처 표시)
- 6~10개 타임라인 이벤트로 정리 (연도 + 한 줄)

### F5. 블로그 초안 자동 생성 (Draft Builder)

- 위 F1~F4를 1500~2500자 마크다운으로 합성
- **구조**:
  ```
  # {선수명}, {오늘의 한 줄 요약}

  ## 오늘의 경기  ← F1
  ## 다시 보는 전성기 — {전성기 시즌}  ← F2 + F3 뉴스 1~2건 인용
  ## {선수명}의 길  ← F4
  ## 마무리 — 다음 경기 관전 포인트
  ```
- **문체**: 친근한 팬 블로그 톤 (전문 통계 용어는 풀어서)
- **출력 위치**: 화면 패널 + `output/storybook/{YYYY-MM-DD}_{선수명}.md` 파일 동시 저장

## 4. 데이터 소스 (Data Sources)

| 영역 | 1차 소스 | 2차 소스 (fallback) | 기존 자산 재사용 |
|------|---------|-------------------|-----------------|

| 선수 서사 | 나무위키 (RAW 텍스트 fetch) | KBO 선수페이지 | 신규 — fetch + 정제 모듈 |

## 5. Out of Scope (Phase 1 명시 제외)

- ❌ 타구단 (10구단 확장) → Phase 2
- ❌ 자동 블로그 발행 (티스토리/네이버 API 연동) → 사용자가 수동 복사·붙여넣기
- ❌ 이미지·하이라이트 영상 첨부 → 텍스트만
- ❌ 다국어 출력
- ❌ 인증·과금
- ❌ 댓글·SNS 공유

## 6. 성공 기준 (Success Criteria)

| 지표 | 목표 | 측정 방법 |
|------|------|----------|
| **자료 수집 시간** | 30분 → 5분 이내 | 사용자 본인 체감 (베타 1주 후 회고) |
| **초안 활용률** | 생성 초안의 70%+ 가 발행에 사용 | 발행글 vs 초안 텍스트 유사도 비교 |
| **데이터 정확도** | 당일 기록 100% 정확 / 전성기 시즌 자동 감지 90%+ 일치 | KBO 공식 데이터 대조 |
| **응답 속도** | 선수 클릭 → 결과 표시 5초 이내 | 클라이언트 측 타이밍 측정 |

## 7. 리스크 & 대응

| 리스크 | 영향 | 대응 |
|--------|------|------|
| 네이버 뉴스 API 일일 quota 초과 (25,000회) | 뉴스 클립 fail | 캐시 7일 + 결과 영구 저장 → 같은 선수 재조회 시 캐시 |
| 나무위키 fetch 차단 / 구조 변경 | 서사 섹션 fail | KBO 공식 선수페이지 fallback + 사용자가 직접 보충하도록 빈 섹션 노출 |
| 신인 선수 (데이터 부족) | 전성기 섹션 fail | "전성기 아직" 라벨 + "현재까지의 성장" 섹션으로 자동 대체 |
| 블로그 초안 품질 (LLM 생성 시 비용) | 토큰 비용 / 할루시네이션 | LLM 미사용 — 템플릿 + 데이터 슬롯 채우기 방식. 사용자 다듬기 전제 |
| 선수 명예훼손 (스캔들 뉴스 인용) | 법적 리스크 | 제외 키워드 필터 + 모든 뉴스에 출처 명시 |

## 8. 아키텍처 스케치 (Pragmatic 3-Layer, 기존과 동일)

```
[UI Layer]                — app/storybook/page.tsx + components/storybook/*
                            검색 입력 · 4섹션 패널 · 초안 미리보기 · 복사/다운로드 버튼
       ↓
[Service Layer]           — src/services/storybook/
                            ├── today.ts        F1: 당일 기록 합성
                            ├── prime.ts        F2: 전성기 자동 감지 (순수 함수, 100% 테스트 강제)
                            ├── news.ts         F3: 네이버 뉴스 검색 + 필터링
                            ├── narrative.ts    F4: 나무위키/KBO fetch + 타임라인 정제
                            └── draft.ts        F5: 마크다운 템플릿 채우기
       ↓
[Data Layer]              — data/players/{id}.json · 신규 data/storybook/cache/
                            네이버 뉴스 7일 캐시 · 나무위키 30일 캐시
                            기존 크롤러 (scripts/crawler/) 그대로 사용
```

**LLM 미사용** — 토큰 비용 0. 모든 합성은 결정론적 템플릿. (Karpathy 원칙: 단순함 우선)

## 부록 A. 블로그 초안 출력 예시 (Sample)

> 입력: 김도영 (3루수 · 78529) · 2026-05-11 경기 후

```markdown
# 김도영, 4타수 3안타 1홈런 — 5월의 황태자

## 오늘의 경기
2026-05-11 vs LG. 4타수 3안타 1홈런 3타점. 시즌 타율 0.341 → 0.348.
멀티히트는 이번 시즌 12번째.

## 다시 보는 전성기 — 2024시즌
2024년 김도영은 만 21세에 38홈런 40도루 KBO 최연소 30-30 클럽에 가입했다.
WAR 8.2, OPS 1.067은 그 해 KBO 전체 1위.

(당시 보도: "스포츠동아 2024-09-28 — 김도영, 한국 야구 새 역사 쓰다")
(스포츠경향 2024-10-05 — "메이저리그 스카우트들이 가장 주목하는 한국 타자")

## 김도영의 길
- 2022: 광주 동성고 → KIA 1차 지명
- 2023: 1군 데뷔, 풀시즌 144경기 출장
- 2024: 30-30 클럽, MVP 수상
- 2025: 시즌 초 부상으로 1개월 결장, 후반기 회복
- 2026: 5월 현재 타율 3할4푼대로 시즌 페이스

## 마무리
다음 경기는 5월 12일 잠실 LG전. 임찬규 선발 예고.
김도영의 LG전 통산 타율은 0.312로 좋은 매치업이 기다린다.
```
