MVP-first 개인 프로젝트. KBO 팬 대상 단일 페이지 대시보드.

**Why:** 마구마구 카드 색상 시스템(엘리트=보라/레어=빨강/스페셜=노랑/노멀=파랑)이 차별화 UX의 핵심이자 유일한 해자.

**핵심 전략 결정:**
- 포지션: Ansoff "제품 개발" — 기존 KBO 팬 시장, 새로운 UX
- 데이터: statiz/스탯티즈 크롤링 (KBO 직접 크롤링보다 안전), 최소 2개 소스 분산
- IP 리스크: 네오위즈 마구마구 브랜드명/로고 사용 금지, "영감 받은 오마주"로만 포지셔닝
- 수익화: 무료 → 자발적 후원(Buy Me a Coffee/토스), 월정액 구독 없음
- 런칭 타이밍: 3월 KBO 개막 전 MVP 배포 목표

**#1 전략 리스크:** 마구마구 IP 침해 클레임 (네오위즈 C&D). 완화: 브랜드명 미사용 + 비상업 프로젝트 유지.

**How to apply:** 기능 제안 시 마구마구 카드 UX 감성 훼손 여부를 항상 체크. 크롤링 설계 시 단일 소스 의존 경계.
