마구마구 카드 UI 스타일을 적용한 KBO 팬 전용 단일 페이지 대시보드. 그린필드 프로젝트.

**Why:** KBO 2024~2025년 흥행 급성장(1088만→1231만 관중), 2030 여성 팬 유입 증가, 기존 앱의 마이팀 집중 + 세이버 지표 동시 제공 공백.

**핵심 경쟁 격차 (채울 곳):**
1. 세이버 데이터(스탯티즈 수준) × 카드 UX(모바일 최적화) — 두 축을 동시에 가진 서비스 없음
2. 마이팀이 기본화면, 리그가 선택 — 반대로 설계된 서비스 현재 없음

**Primary Persona:** 이수연 (34세 직장인 LG 팬) — 점심·퇴근길 5분 확인, 마이팀 집중, 카드 UI로 SNS 공유

**TAM/SAM/SOM:** TAM 80~100억 원/년, SAM 20억 원/년, SOM 1.5억(1년차)→6억(3년차)

**핵심 불만 (커뮤니티):** 알림 설정 4단계 복잡, WAR 등 세이버 없음, KBO 공식앱 버그 심각, 모바일에서 스탯티즈 UX 불가, 중계 유료화로 텍스트 정보 수요 증가

**How to apply:** 기능 우선순위, UI 결정, 온보딩 설계 시 참고. "마이팀 설정 30초 내 완료, 세이버+카드 통합 뷰"가 핵심 가치 제안.
